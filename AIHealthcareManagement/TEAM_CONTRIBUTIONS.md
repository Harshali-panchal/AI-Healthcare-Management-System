# Project Overview

The **AI Healthcare Management System** is a web-based healthcare platform designed to manage patient information, doctors, appointments, medical records, prescriptions, AI-assisted symptom analysis, reminders, notifications, and role-based access.

The system is being developed using **ASP.NET Core (.NET 8), Entity Framework Core, C#, and Microsoft SQL Server**.

---

# Technology Stack

- **Backend:** ASP.NET Core MVC / C#
- **Framework:** .NET 8
- **ORM:** Entity Framework Core
- **Database:** Microsoft SQL Server
- **Frontend:** HTML, CSS, Bootstrap, Razor Views
- **Development Environment:** Visual Studio
- **Version Control:** Git & GitHub
- **AI Module:** AI-assisted symptom analysis
- **Architecture:** MVC with Entity Framework Core

# Database Modules

The current database design includes the following major entities:

- Users
- Roles
- Patients
- Doctors
- Doctor Availability
- Administrators
- Appointments
- Medical Records
- Prescriptions
- AI Symptom Assessments
- Reminders
- Notifications
- Audit Logs

The database uses relationships and foreign keys to maintain consistency between users, patients, doctors, appointments, medical records, prescriptions, and other healthcare modules.
